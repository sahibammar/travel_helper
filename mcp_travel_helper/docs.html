Travel Helper MCP Server

Provide agents and LLMs with flight deals and destination info from data/travel_helper.json.

Introduction

The Travel Helper MCP Server follows the Model Context Protocol, allowing agents and LLMs to query cheap round-trip flight deals (from Weeze/Köln/Dortmund to Europe) and destination details. Data is read from a local data/travel_helper.json file produced by travel_helper.py — no external APIs are called.

Overview

The Model Context Protocol is a standardized protocol that enables code agents and LLMs to connect to MCP servers to manage resources and complete tasks using natural language prompts.

An MCP client is an application that connects to an MCP server, such as Windsurf, Cursor, Claude, or VS Code Copilot. This server supports:

  • STDIO mode — for clients that run the server as a subprocess (e.g. Cursor, Claude Desktop).
  • Streamable HTTP mode — for clients that connect via URL (e.g. https://mcp.trivago.com/mcp-style). Endpoint: /mcp.

Sample Prompts

Here are some examples of how you can use the Travel Helper MCP Server:

  • "What are the cheapest flight deals right now?"
  • "List flight deals to Barcelona."
  • "Show me full details and flight options for Manchester."
  • "What are the top 5 cheapest destinations?"
  • "Find flights to Olsztyn with outbound dates in March 2026."

Available Tools

The Travel Helper MCP Server offers the following tools:

Tool Name Description
travel_deals_data_status Show which data file is loaded and how many deals (use if you see no results).
travel_deals_list List all destination deal groups (optional limit).
travel_deals_search Search deal groups by destination name (substring, case-insensitive).
travel_deals_destination Full details for one destination (flights + destination_info, weather, attractions).
travel_deals_cheapest Top N cheapest deals by min_total_eur.
travel_deals_flights_for_destination Flight options for a destination, with optional outbound date range filter.

Travel Helper MCP Configuration

You can add the Travel Helper MCP server in two ways:

1. Streamable HTTP (URL) — when the server is running with --transport streamable-http:

{
  "mcpServers": {
    "travel-helper": {
      "url": "http://127.0.0.1:8000/mcp"
    }
  }
}

2. STDIO (command) — for Cursor, Claude Desktop, and similar clients that spawn the server:

{
  "mcpServers": {
    "travel-helper": {
      "command": "/path/to/travel_helper/.venv-travel/bin/python",
      "args": ["-m", "mcp_travel_helper"],
      "cwd": "/path/to/travel_helper",
      "env": {}
    }
  }
}

Optional: set TRAVEL_HELPER_JSON in env if your JSON file is in a different path.

Running the Server

From the project root with the virtual environment activated:

  • STDIO (default): python -m mcp_travel_helper
  • Streamable HTTP: python -m mcp_travel_helper --transport streamable-http [--host 127.0.0.1] [--port 8000]

When using Streamable HTTP, documentation is available at /docs (this page).

Installation Guide

Cursor — Add the Travel Helper MCP server in Cursor settings (MCP) using the STDIO configuration above. Use the full path to your python and cwd.

VS Code — Configure MCP in your editor settings and point to either the server URL (Streamable HTTP) or the command (STDIO). See the Model Context Protocol documentation for client-specific steps.
